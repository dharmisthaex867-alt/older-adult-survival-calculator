How the raw scores are interpreted

Depressive symptoms: CHARLS and KLoSA use CES-D 0–30; ELSA and HRS use CES-D 0–8.

Cognition: CHARLS uses a 0–20 composite; ELSA a 0–24 composite; HRS the 0–27 cognition summary; KLoSA a 0–30 K-MMSE component total. These totals must follow the study's component rules, not another scale with the same maximum.

Income: Q1 is exactly zero income. Positive incomes are split into thirds within each cohort to obtain Q2–Q4. There is no universal currency cutoff.

About this research tool

The underlying study included 46,023 participants from four ageing cohorts in China, England, South Korea and the United States. CHARLS, ELSA and KLoSA were used for development; HRS was reserved for external validation. Cox elastic net was the primary model selected by the prespecified cross-validation rule.

This page uses coefficients, scaling parameters and baseline survival functions exported from the five saved CoxNet models fitted for external validation. Complete input is required, so this interface does not perform the original missing-data imputation. The source cohort selects raw-score conversion only; it does not select a cohort-specific prediction model.
